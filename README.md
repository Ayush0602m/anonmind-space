# anonmind-space

Anonymous mental health support with safe chat rooms, emergency resources, and helpful articles.

## Getting Started

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

Start the WebSocket chat server in a second terminal:

```sh
npm run chat:server
```

Build for production:

```sh
npm run build
```

Preview the production build:

```sh
npm run preview
```

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
